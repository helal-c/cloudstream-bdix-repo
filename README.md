# ⚡ Xtreme'x BDIX - CloudStream 3 Repository

Bangladeshi BDIX broadband এবং ISP ব্যবহারকারীদের জন্য ডেডিকেটেড CloudStream 3 প্লাগিন রিপোজিটরি।

---

### 📥 CloudStream 3 এ যেভাবে যুক্ত করবেন:

1. **CloudStream 3** অ্যাপ ওপেন করুন।
2. **Settings** ⚙️ → **Extensions** এ যান।
3. **Add Repository** তে ক্লিক করুন।
4. নিচের তথ্যগুলো দিন:
   * **Repository Name:** `Xtreme'x BDIX`
   * **Repository URL:** `https://raw.githubusercontent.com/helal-c/cloudstream-bdix-repo/builds/repo.json`
5. **Download** বাটনে চাপুন।
6. এরপর **Xtreme'x Live TV** এবং **Xtreme'x BDIX** প্লাগিন দুটি ইনস্টল করে নিন।
